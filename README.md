# Data Cleaning Project

This project focuses on cleaning and preprocessing YouTube dataset, preparing it for further analysis. The dataset contains various attributes such as video statistics, user comments, and channel details. The goal is to ensure the data is clean, free of missing or erroneous values, and ready for use in machine learning or other analysis tasks.

## Project Overview
The project includes the following key steps:
- **Data Loading:** Importing and loading YouTube and related data from various sources.
- **Data Cleaning:** Handling missing data, removing duplicates, and cleaning inconsistent values.
- **Handling Large Files:** Some files in the dataset are quite large, and due to size constraints, they were not uploaded to this repository. These large files may include videos, extensive logs, or raw data files.

## Key Features
- **Missing Data Handling:** The project identifies and handles missing values by filling in with appropriate methods (e.g., median, mode).
- **Duplicate Removal:** Duplicate rows are identified and removed to ensure clean data.
- **Data Transformation:** The dataset is transformed (e.g., converting text data to lowercase) to standardize information.

## Files Included
- **data_cleaning.py:** Python script that contains the logic for data cleaning.
